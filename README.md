# 🐟 DeepSeek 桌宠 · 小深

一个可爱又动态的 Windows 桌面宠物，基于 Electron。它会漂浮、摇摆、呼吸，还会朝你的光标倾斜；能一键启动 DeepSeek，把文件「吃掉」丢进回收站，支持换肤、图集动画和开机自启。

## ✨ 功能

| 操作 | 效果 |
| --- | --- |
| 🖱️ 左键拖动 | 把桌宠抱到屏幕任意位置（松手轻轻弹一下） |
| 👆 单击 | 戳戳它：果冻式轻微抖动 + 星光 |
| 🖱️ 双击 | 打开 **DeepSeek 网页版**（https://chat.deepseek.com/） |
| 🗑️ 拖文件/文件夹到它身上 | 播放「咀嚼」动画，并把文件**丢进回收站** |
| 🖱️ 右键 | 打开功能菜单 |
| 🎨 右键 → 换肤 | 内置「经典蓝」，可导入 PNG 立绘 / 图集动画皮肤 |
| 🎬 图集动画皮肤 | 导入 1536×1872 精灵图集（8列×9行，每帧 192×208）自动获得**真帧动画**（呼吸/跑步/挥手/跳跃/打盹…） |
| 🚀 右键 → 开机自启 | 随 Windows 开机自动弹出（默认开启，可关） |
| 🤖 右键 → 启动 dsh | 打开 dsh 网页（未运行则后台自动拉起 `dsh web` 后打开，不弹控制台窗口） |
| 📌 常驻置顶 | 桌宠始终悬浮在所有窗口之上（常开，不可关闭） |
| 🙈 右键 → 隐藏桌宠 | 藏到托盘不退出，托盘图标 / 双击托盘可唤回 |
| 🎉 右键 → 来点动作 | 随机来一段小动作 |

闲置时会漂浮摇摆 + 呼吸缩放，45 秒无交互自动打盹（循环睡觉动画），点击/拖动/投喂/右键即可唤醒。

## 🚀 运行

### 方式一：一键启动

双击 `启动桌宠.bat`（或 `start-pet.bat`）。首次运行会自动安装 Electron 依赖（需要联网）。

### 方式二：手动运行

```bash
npm install
npm start
```

## 🧪 自检

```bash
npm run selftest
```

会在真实窗口上自动跑 13 项回归（渲染初始化 / 图集激活 / 换肤往返 / 拖动 / 置顶相关 / 网站校验 / 隐藏唤回 / 截图），结果写进 `pet-log.txt` 的 `[selftest]` 行，全部通过退出码为 0。适合改动后快速回归。

## 🎨 换肤说明

- 内置皮肤：**经典蓝**（静态立绘，启动时自动去白底）。
- 「导入 PNG 立绘」会打开文件选择框，选中的图片会被复制到 `skins\` 目录并立刻切换；建议使用**透明背景 PNG**。
- 导入的图片如果是 **1536×1872 的精灵图集**（8列×9行，每帧 192×208），会自动识别为**图集动画皮肤**：待机呼吸、跑步（拖动时）、挥手、跳跃（戳它时）、打盹等真帧动画，皮肤列表里带 🎬 标记。
- 图集皮肤可配同名 `.layout.json` 自定义布局（多行动画 / 镜像 / 每套帧时长）。
- 选择的皮肤会记录在 `pet-config.json` 中，下次启动自动应用。

## 🚀 开机自启说明

- 首次运行会自动写入启动项（注册表 `HKCU\...\CurrentVersion\Run` 的 `DeepSeekPet`），之后每次启动自动弹出宠物。
- 右键菜单或托盘菜单可随时开关；关闭后会删除该注册表项。

## 🛠️ 其他说明

- 桌宠常驻**系统托盘**，右键托盘图标可随时「显示桌宠 / 退出」。
- 删除文件走的是系统**回收站**（`shell.trashItem`），不是永久删除，误删可从回收站还原。
- 宠物图来自 `assets\pet.jpg`；程序启动时会在内存里**裁掉底部文字并去除白色背景**，得到透明立绘。
- 诊断日志写在 `pet-log.txt`，排查问题时可以发给开发者。

## 📁 文件结构

```
├── main.js          主进程：窗口、托盘、自启、皮肤、启动应用、回收站、拖动
├── preload.js       安全桥接（contextBridge + webUtils）
├── index.html       界面结构
├── style.css        样式与动画
├── renderer.js      动效、交互、去背景、换肤、图集动画引擎、打盹行为
├── assets/pet.jpg   默认宠物立绘
├── skins/           导入的皮肤（自动创建）
├── pet-config.json  配置（当前皮肤 / 开机自启）
├── pet-log.txt      诊断日志
├── 启动桌宠.bat      一键启动脚本（CRLF）
└── package.json
```
